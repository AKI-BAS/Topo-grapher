How to Import a DXF Contour File into SketchUp

Import DXF contours into SketchUp Pro and turn them into a real 3D terrain surface using the Sandbox tool. Common pitfalls covered.
28 July 2026 · 4 min · Aki

Contour lines are the most common way to receive terrain data from a surveyor or planning authority. Getting them into SketchUp and turning them into an actual 3D surface is a two-stage process: import the DXF, then triangulate.

This post covers both stages, plus the small mistakes that produce a flat surface instead of a hill.

Before you import#

Two things to check on the DXF file first, because both cause silent failures later:

1. The contours must be 3D polylines, not 2D. A 2D polyline sits at Z=0 no matter what its elevation label says. If your DXF was drawn as an annotated 2D drawing with elevation numbers written next to the lines, SketchUp will import it flat. Open the file in a CAD viewer and rotate the view. If the contours look like a flat plan from every angle, they are 2D and you need to ask the sender for a 3D version.

2. Confirm the units. DXF has no reliable unit metadata. Ask whether the file is in metres, feet, or something else, and match your SketchUp template accordingly.

Import DXF into SketchUp#

DXF import requires SketchUp Pro. SketchUp Free (web) does not support DXF.

  1. Open your SketchUp Pro project. Set the template units to match the DXF (usually metres for European projects, feet for US).
  2. Go to File → Import.
  3. Change the file type filter to AutoCAD Files (*.dwg, *.dxf).
  4. Select the DXF file.
  5. Click Options and confirm the units. Untick “Merge coplanar faces” if it is on — for contours you want the raw lines preserved.
  6. Click Import.

The contour lines should appear in the model space. If the model looks empty, use Camera → Zoom Extents — DXF files often import at large coordinate offsets and the geometry is off-screen.

Turn the contours into a surface#

The imported contours are still just lines. To model over them or place a building on them, you need a triangulated surface (TIN). SketchUp Pro’s Sandbox tools handle this.

If the Sandbox toolbar is not visible:

  1. Window → Preferences → Extensions (Windows) or SketchUp → Preferences → Extensions (macOS).
  2. Tick Sandbox Tools.
  3. Close preferences. The Sandbox toolbar is now available via View → Toolbars → Sandbox.

Then:

  1. Select all the imported contour lines. Edit → Select All works if the DXF only contained contours; otherwise use a rubber-band selection or filter by layer.
  2. Click Sandbox → From Contours.
  3. Wait. On a dense contour file this can take 30 seconds to several minutes.
  4. Sandbox generates a triangulated mesh draped over the contours as a new group.

You now have a 3D terrain surface. The original contour lines are still in the model — either delete them or move them to a hidden layer for reference.

Common problems#

“From Contours” is greyed out. You selected geometry that is not lines, or you selected nothing. Reselect only the contour polylines.

The surface is completely flat. The contours were 2D. Go back to your source data.

The surface has spikes, holes, or wild triangles. Usually caused by mislabelled contours (a 5m line accidentally at 50m), broken contour segments, or coincident lines at different heights. Zoom in on the spikes and fix or delete the offending lines, then re-run From Contours.

SketchUp hangs on From Contours. Too many contours for the machine. Simplify the DXF first: delete every second contour interval (keep the 5m contours, drop the 2.5m), or trim to only the area you actually need.

The imported geometry is thousands of units from origin. DXF files from GIS-based sources often use full national grid or UTM coordinates. Move the entire imported group closer to origin before triangulating — SketchUp’s precision degrades severely far from origin, and Sandbox triangulation can fail outright.

When DXF is the wrong starting point#

DXF contours are convenient when they are already the deliverable, but they lose fidelity compared to raw elevation data. Contours are an interpretation of the underlying surface at fixed intervals, so a 1m contour interval loses everything smaller than 1m.

If you have a choice, an XYZ point CSV or a direct mesh export produces a more accurate SketchUp surface than DXF contours ever will.
